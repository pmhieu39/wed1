# Wed Chat AI

Trang web đơn giản giúp trò chuyện với nhiều mô hình AI khác nhau.

## Sử dụng
1. Mở `index.html` trong trình duyệt.
2. Chọn nhà cung cấp AI và nhập API key.
3. Nhấn **Lưu API** để ghi nhớ khóa trong trình duyệt.
4. Gõ tin nhắn và nhấn "Gửi" hoặc Enter để nhận phản hồi.

## Lưu ý
- API key được lưu trong `localStorage` và gửi trực tiếp tới nhà cung cấp. Không dùng khóa bí mật trên máy công cộng.
- Dự án chỉ bao gồm mã nguồn phía khách; không có máy chủ backend.
