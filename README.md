# Wed Chat AI

Trang web đơn giản giúp trò chuyện với AI thông qua OpenAI API.

## Sử dụng
1. Mở `index.html` trong trình duyệt.
2. Nhập API key OpenAI vào ô "API Key".
3. Gõ tin nhắn và nhấn "Gửi" để nhận phản hồi.

## Lưu ý
- API key được gửi trực tiếp từ trình duyệt tới OpenAI. Không dùng khóa bí mật trên máy công cộng.
- Dự án chỉ bao gồm mã nguồn phía khách; không có máy chủ backend.
